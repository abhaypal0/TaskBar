# 💎 Glassmorphism Task Manager

A premium, open-source Chrome Extension designed with a sleek glassmorphism aesthetic. This tool helps users stay productive with a persistent, secure, and beautiful task-tracking interface.



## 🌟 Key Features

- **Glassmorphism UI:** Advanced CSS backdrop-filter effects for a modern "frosted glass" look.
- **Persistent Storage:** Integrated with `chrome.storage.local` to ensure user data is saved securely and stays available after browser restarts.
- **Live Activity Badge:** Dynamic icon badge that shows the number of pending tasks in real-time.
- **Interactive Logic:** Full CRUD (Create, Read, Update, Delete) capabilities with smooth CSS animations.
- **Secure by Design:** Built with Manifest V3 standards to ensure privacy and security.

## 🛠️ Built With

- **HTML5** - Structured semantic markup.
- **CSS3** - Custom glassmorphism styling and keyframe animations.
- **JavaScript (ES6+)** - Logic for task management and Chrome API integration.
- **Chrome Storage API** - For secure data persistence.
